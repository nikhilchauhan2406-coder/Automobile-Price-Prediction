# Automobile Price Prediction
## Project Overview
This project focuses on predicting automobile prices using supervised machine learning regression techniques.It includes exploratory data analysis, data cleaning, missing-value treatment, feature engineering, model development, performance evaluation, and final price prediction.
## Project Objective
To develop and evaluate machine learning regression models that estimate automobile prices based on vehicle specifications and related attributes.
## Dataset
- Automobile Imports dataset
- Approximately 201 records and 26 attributes
- Target variable: `price`
## Technologies and Libraries
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
## Project Workflow
1. Data loading and inspection
2. Exploratory Data Analysis(EDA)
3. Data Cleaning and missing-value treatment
4. Numerical and Categorical feature preprocessing
5. Feature correlation analysis
6. Model training and evaluation
7. Feature importance analysis
8. Final model training and saving
9. Sample automobile price prediction
## Machine Learning Models
The following regression algorithms were evaluated:
1. Linear Regression
2. Decision Tree Regression
3. Random Forest Regression
4. Gradient Boosting Regression
## Data Preprocessing
- Missing-value imputation
- One-Hot Encoding for categorical variables
- StandardScaler for numerical features
- ColumnTransformer and preprocessing pipeline
## Model Evaluation
Models were evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error(RMSE)
- R-squared (R<sup>2</sup>)

## Best Performing Model
Gradient Boosting Regression achieved the best comparative performance in this project.
The recorded model performance was approximately:
- MAE: 1554.13
- RMSE: 2472.19
- R<sup>2</sup>: 0.9500

This project demonstrates an end-to-end machine learning regression workflow for automobile price prediction, from data preprocessing and model comparison to final model development and prediction.
